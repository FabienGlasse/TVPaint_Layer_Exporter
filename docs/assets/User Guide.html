QUICK START / 01

Get ready to export

TVPaint layer exporter is a fast way to make image sequences. No coding is needed. Start with Auto Mode; or use Manual Mode if you want to fuse layers or have your own way of organising your files.

Install once

1. Save your work and close TVPaint. You will need to have an internet connection.

2. Extract the package you received. For the guided installer, open Install.bat. For the conventional installer, open TVPaintLayerExporterSetup.exe, finish its wizard and leave the final configuration option selected.

3. Each setup stage is explained to you. Choose Y to continue or N to stop; press Enter when prompted. If asked to install Python, let setup do it for you.

4. Choose your TVPaint version from the numbered list. If it is missing, choose B and find the TVPaint application on your computer.

5. If Windows asks for administrator permission to connect the exporter to TVPaint, approve it or ask your studio/IT contact. Wait for SETUP COMPLETE.

6. Open TVPaint again, then use the TVPaint Layer Exporter desktop shortcut.

Your first export - Auto Mode

Open the intended project and clip. Keep only that TVPaint application open. The exporter checks the connection and lists the layers; use Refresh connection after changing projects, clips or layers.

Auto Mode creates a new dated folder for each export. Each checked layer becomes its own sequence by default. Settings start collapsed: click an Edit... heading to open them. Manual Mode shows all settings. The app always opens in Auto Mode.

Check the layers you need, and if needed you can change export settings (such as image format or frame range), then browse to your Output folder. You will be given a filename preview and orange readiness line. Click Export layers and leave TVPaint idle until the export finishes. You will see your layers Activate/Inactivate and restored after export.

Windows 64-bit. Intended versions: TVPaint 11.7.3 and 12.1.0.

The exporter does not save your project; save your work before exporting.

SETTINGS / 02

Choose your delivery

The preview stays visible as you adjust settings. Folder rows are dividers, not selectable layers; hidden folders and layers are labelled in the stack.

Setting What it does
Image format PNG, JPEG, TIFF, TGA or BMP. The exporter is made for image sequences.
Background Unchecked means transparency. JPEG and BMP need a background, so it is enabled automatically. When checked, the exporter uses TVPaint's background colour, or white if no colour is set.
Frame range Use the frame numbers shown in TVPaint. Set to Full clip restores the complete range. Both end frames are included, including held drawings.
Folder prefix / Filename prefix Independent optional prefixes. Folder prefix COMP and Filename prefix SH010 give COMP_Character/SH010_Character_001.png. Folder prefix has no effect with flat output.
Start numbering / Extra digits Choose the first output number and minimum number of digits. Start 1 with 3 digits gives 001; start 1001 with 4 digits gives 1001.

Export choices

Export as one sequence combines all checked layers into the same images, using their TVPaint stacking order. Unchecked layers are excluded. Leave this off to export each checked layer separately.

Put all files directly in the output folder controls the folder layout. Turn it on for images at the export-folder root, or leave it off for one subfolder per sequence. It does not combine layers by itself.

Names you can check before export

When combining layers, Sequence name follows the top checked layer. Type your own name for the current selection, or use Use top layer or Use bottom layer. Changing the checked layers resets it to the new top layer. The optional prefix is added before that name.

Example: SH010_Character_001.png. Export folders look like TVPaint_export_20260916_143303: date, then local time to the second. If that folder already exists, a simple _2, _3, etc. keeps it separate.

Unsupported filename characters are replaced and colliding layer names are made distinct. The orange message and preview show the result. Folder, naming, format and background preferences are remembered.

ARTIST WORKFLOW / 03

Build a delivery in Manual Mode

Use this when extra working layers need to be delivered together, or if your workflow needs an extra level of control. Each export adds a new sequence to the same session folder.

1. Choose Manual Mode, on the left of Refresh connection. Export as one sequence turns on automatically.

2. Choose the output location before your first export. Decide whether you want sequence subfolders or all images directly in the export folder.

3. Click None, then check the two layers that belong together - for example, Character lineart and Character lineart details. Only checked layers are included, even if other layers are visible in TVPaint.

4. Check Sequence name. It defaults to whichever checked layer is highest in the layer list. You can type Character_lineart or another delivery name instead.

5. Click Export layers. The first export creates the session folder. The app shows its location and keeps using it for the rest of this Manual session.

6. Uncheck those layers, check your next layer - for example, Shadow - and export again. It becomes a separate sequence in that same folder.

7. Repeat as needed. You can also turn off Export as one sequence to export a series of individual checked layers separately into the same session folder.

If a sequence name already exists

An orange message appears and Export is unavailable. Choose a different sequence name or prefix to keep the existing images. In Manual Mode only, Overwrite layers enables Export and replaces the matching sequence images while keeping the other exports in the session folder. If you are continuing an interrupted export, use Resume interrupted export instead.

When the session ends

Switching to Auto Mode releases the session folder and unchecks Export as one sequence. Closing the app also ends the session. Returning to Manual Mode starts a fresh session; previous exports stay on disk.

The output location is fixed once the Manual session folder exists. To choose a different location, switch to Auto Mode and then back to Manual Mode. Refreshing the connection does not end the Manual session.

DELIVERY / 04

Finish, cancel and resume

Check the result

The progress bar shows completed frames, with elapsed time and an estimate of time remaining. When it finishes, use Open export folder to inspect the images. You can also check Open delivery report to read the summary.

Delivery Report.txt starts with the project, clip and full source stack, in top-to-bottom order. Folders appear in brackets; hidden items are labelled. Each export appends its frame range, format, sequence details, file counts and status to the same report. Layer structure can be of use for a compositing artist to know in which order layers were organised.

export_manifest.json is hidden by default in Windows. It holds the latest export's resume record and remains readable by the exporter. Keep it with the folder; there is no need to open or edit it.

Cancel or resume

1. Click Cancel and wait for the current operation to stop. The exporter attempts to restore the original layer visibility, current layer, frame and export settings.

2. Keep the original project and clip open and unchanged. Choose Resume interrupted export, then select the interrupted export folder.

3. Click Resume export. Original export settings are reused. Previously exported frames are checked against TVPaint before missing frames are written; this check can take time.

If drawings, existing images, or the scene/layer identity have changed, resume stops to avoid mixing different versions. Start a fresh export instead. In a shared Manual folder, resume the interrupted export before starting another export, because only the latest resume record is kept.

Deliver the whole folder

Once every intended export says complete in the report. You can send the dated export folder, including images and report.

If something goes wrong

For a connection problem, keep only the intended TVPaint instance open and refresh. Restart TVPaint if necessary. For a path or permission message, choose a shorter writable output location. Send your studio/IT the on-screen error and delivery report if you need help.

Uninstall

Close the exporter. In Windows Settings under Apps, select TVPaint Layer Exporter and Uninstall, or open Uninstall.bat in its installation folder. Exported files are always kept.

Optional choices remove Python and/or the TVPaint connection component; both are kept by default. Other tools may need them. Close TVPaint before removing its component. Approve Windows permission if asked, and finish Python's official uninstall window.
